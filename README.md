# Первый IT-лицей | Новая цифровая экосистема (v2.0)

Современная, безопасная и интеллектуальная замена устаревшего портала `flyceum.ru`. Проект разработан в рамках школьного хакатона «AI: Орбита будущего».

## 🚀 Описание проекта
Данный проект представляет собой полный редизайн и архитектурное обновление официального сайта Первого IT-лицея. Главная проблема старого сайта — устаревший табличный дизайн, отсутствие мобильной адаптации, работа по небезопасному протоколу HTTP и отсутствие интерактивности. 

Новое решение предлагает формат Single Page Application (SPA), адаптивный дизайн, безопасную архитектуру (HTTPS/Vercel) и интеграцию нейросетей для автоматизации модерации обращений.

## ⚖️ Сравнение: Старый сайт (flyceum.ru) vs Новый проект

| Критерий | Старый сайт | Наше решение |
| :--- | :--- | :--- |
| **Архитектура** | Табличная верстка (HTML 4), устаревший код | SPA (Single Page Application), Vanilla JS + модули |
| **Мобильная версия** | Отсутствует (неудобно читать с телефона) | Полностью адаптивный интерфейс (Tailwind CSS) |
| **Безопасность** | HTTP (незащищенное соединение) | HTTPS, Firebase Security Rules, защита от XSS/SQLi |
| **База данных** | Локальная, сложная в обновлении | Firebase Firestore (NoSQL, обновления в реальном времени) |
| **Обратная связь** | Отсутствует / обычный email | «Виртуальная приемная» с математической каптчей |
| **Искусственный Интеллект** | Нет | **AI-Модерация (OpenAI GPT-4o-mini)** всех обращений |

## 🧠 Интеграция AI (Киллер-фича)
В систему внедрена **Виртуальная приемная** с многоуровневой защитой:
1. Математическая каптча для защиты от спам-ботов.
2. Проверка текста нейросетью **GPT-4o-mini** (OpenAI). ИИ анализирует контекст сообщения и блокирует скрытые оскорбления, токсичность или нецензурную лексику в адрес учеников и педагогов.

## 🛠 Технический стек
* **Frontend:** HTML5, Tailwind CSS (через CDN для быстрой разработки), JavaScript (ES6+).
* **Backend/BaaS:** Firebase (Firestore для новостей и писем, Authentication для админ-панели).
* **AI API:** OpenAI API (модель `gpt-4o-mini`).
* **Деплой и хостинг:** Vercel (CI/CD с автоматической сборкой из GitHub).
* **Хранение медиа:** GitHub Raw URLs (для фото педагогов) и ImgBB API (для новостей).

## ⚙️ Инструкция по локальному запуску

1. Склонируйте репозиторий:
   ```bash
   git clone [https://github.com/asecretmanthatyoudontneedtoknow/flyceum-hackaton.git](https://github.com/asecretmanthatyoudontneedtoknow/flyceum-hackaton.git)
   cd flyceum-hackaton```

2. Создайте .env и напишите туда ключи API
3. Установить Vite
4. Локально запустить:
   ```bash
   npm run dev
   ```
